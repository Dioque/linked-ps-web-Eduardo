# Landing Page — Consultório de Psicologia e Psicoterapia

**Nome completo:** EDUARDO GONÇALVES RODRIGUES

---

## Breve descrição do projeto

Este projeto foi desenvolvido como parte do Processo Seletivo da **Linked — Empresa Júnior** na modalidade de Desenvolvimento Front-End (Landing Page). O objetivo principal do desafio consiste em transformar em código um layout pronto no Figma (referente a uma página institucional de um consultório de psicologia e psicoterapia), garantindo fidelidade visual ao design original, organização de código e responsividade, sem a utilização de bibliotecas ou frameworks de componentes prontos.

---

## Tecnologias e ferramentas utilizadas

- **React.js** — Biblioteca principal para construção da interface de utilizador.
- **Vite** — Ferramenta de build e servidor de desenvolvimento rápido.
- **CSS3 Puro** — Estilização completa sem frameworks externos (uso de CSS Variables, Flexbox, CSS Grid, Pseudo-elementos e Media Queries).
- **Node.js & npm** — Ambiente de execução e gestão de dependências.
- **Git & GitHub** — Controlo de versão e hospedagem do código.

## Instruções de como rodar o projeto localmente

### Pré-requisitos
Para executar este projeto na sua máquina, precisa de ter o **Node.js** (versão 18 ou superior) e o **Git** instalados.

### Passo a passo

1. Clone este repositório no seu terminal:
   `git clone https://github.com/Dioque/linked-ps-web-Eduardo.git`

2. Acesse a pasta do projeto:
   `cd linked-ps-web-eduardo-goncalves`

3. Instale todas as dependências necessárias e inicie:
   `npm install && npm start`

5. Abra o navegador no endereço exibido no terminal (geralmente `http://localhost:5173`).
